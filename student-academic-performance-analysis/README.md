# Student Academic Performance Analysis

## 📌 Project Overview

This project analyzes student academic performance across six subjects for one academic term. The analysis explores performance patterns based on gender, subject, class level, and attendance.

The goal was to use data to identify areas of strong performance and subjects requiring additional academic support.

## 🎯 Objectives

- Analyze student academic performance.
- Identify performance patterns based on gender, subject, and attendance.
- Compare academic performance across different class levels.
- Identify subjects with lower average scores.
- Generate insights that can support better teaching and learning decisions.

## ❓ Questions Analyzed

- Do male and female students perform differently?
- Does attendance affect exam performance?
- What is the average exam score by subject?
- Which class level performs best overall?
- Which subjects have the lowest average scores?

## 🛠️ Tools Used

- Microsoft Excel
- PivotTables
- Charts and Data Visualization
- Data Cleaning and Validation

## 📊 Analysis Performed

The dataset was analyzed to compare:

- Average exam score by subject
- Average exam score by gender
- Average exam score by class level
- Average exam score at different attendance levels
- Overall academic performance

PivotTables and charts were used to summarize the data and communicate the findings.

## 🔍 Key Findings

### Performance by Subject

| Subject | Average Exam Score |
|---|---:|
| Biology | 75.00 |
| Computer | 74.50 |
| Chemistry | 70.30 |
| Physics | 68.58 |
| Maths | 61.00 |
| English | 59.22 |

The overall average exam score was **65.16**. Biology recorded the highest average score, while English recorded the lowest. 

### Performance by Gender

| Gender | Average Exam Score |
|---|---:|
| Female | 66.42 |
| Male | 63.74 |

Female students recorded a higher overall average score than male students in the analyzed dataset.

### Performance by Class

| Class | Average Exam Score |
|---|---:|
| SS1 | 69.03 |
| SS2 | 62.42 |
| SS3 | 63.13 |

SS1 recorded the highest overall average among the three class levels.

### Attendance and Performance

The analysis also compared average exam scores across different attendance percentages to examine the relationship between attendance and academic performance.

## 💡 Recommendations

- Provide additional academic support for subjects with lower average scores, particularly English.
- Encourage regular and punctual attendance.
- Review effective teaching approaches used in higher-performing subjects and consider how they can be applied to subjects with lower performance.
- Use student performance data to support academic planning and decision-making.
