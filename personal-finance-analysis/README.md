# Personal Finance Analysis

## 📌 Project Overview

This project analyzes personal income and expenses to understand spending patterns, financial trends and overall cash flow.

The project uses Microsoft Excel and Power BI to organize, analyze and visualize financial data in a clear and interactive format.

## 🎯 Objectives

- Analyze income and expenses over time.
- Identify major spending categories.
- Examine monthly financial trends.
- Compare income with expenses.
- Identify areas of higher spending.
- Create visual reports to support better financial decision-making.

## 🛠️ Tools Used

- Microsoft Excel
- Power BI
- Data Cleaning
- Data Analysis
- Data Visualization
- Dashboard Development

## 📊 Analysis Performed

The analysis examined:

- Monthly income
- Monthly expenses
- Expense categories
- Spending patterns
- Income versus expenses
- Financial trends over time

Excel was used to organize and analyze the financial data, while Power BI was used to create interactive visualizations and dashboard insights.

## 📈 Power BI Dashboard

The Power BI dashboard provides a visual overview of financial performance and allows the data to be explored through interactive visualizations.

Key areas include:

- Income analysis
- Expense analysis
- Income versus expense trends
- Spending categories
- Monthly financial performance

## 🔍 Key Insights

The analysis highlights patterns in income and expenditure and provides a clearer understanding of how spending changes over time.

The dashboard can be used to identify major expense categories and periods of higher or lower spending.

## 💡 Recommendations

- Monitor major spending categories regularly.
- Compare monthly income against expenses.
- Identify areas where unnecessary spending can be reduced.
- Use financial dashboards to monitor spending patterns and support budgeting decisions.

## 📌 Conclusion

This project demonstrates how Excel and Power BI can be used together to transform financial data into clear visual insights and support better financial planning and decision-making.
