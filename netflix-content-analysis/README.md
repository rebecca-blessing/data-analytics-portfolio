# Netflix Content Analysis

## 📌 Project Overview

This project analyzes Netflix content using Microsoft Excel to explore the distribution, characteristics and trends within the Netflix dataset.

The project includes data analysis, summary tables, visualizations and an interactive dashboard designed to present key findings in an easy-to-understand format.

## 🎯 Objectives

- Analyze the distribution of Movies and TV Shows on Netflix.
- Examine content distribution by release year.
- Analyze Netflix content ratings.
- Identify frequently appearing actors in the dataset.
- Identify top directors.
- Explore the most common content genres.
- Create a visual dashboard to communicate the findings.

## 🛠️ Tools & Techniques

- Microsoft Excel
- Data Analysis
- PivotTables
- Summary Tables
- Charts
- Data Visualization
- Dashboard Development
- Interactive Filtering

## 📊 Dataset

The dataset contains Netflix titles and information including:

- Show ID
- Type
- Title
- Director
- Cast
- Country
- Date Added
- Release Year
- Rating
- Duration
- Genre
- Description

The dataset contains approximately 8,800 Netflix records.

## 🔍 Analysis Performed

### 1. Movies vs TV Shows

The analysis examined the proportion of Movies and TV Shows in the dataset.

- Movies: approximately **69.6%**
- TV Shows: approximately **30.4%**

### 2. Content by Release Year

The analysis examined Netflix content released between 2015 and 2021.

The highest number of titles in the analyzed release-year data was recorded in **2018**, with 1,147 titles.

### 3. Content Ratings

The project analyzed the distribution of Netflix titles across different ratings.

The most frequently occurring rating in the dataset was **TV-MA**, followed by **TV-14** and **TV-PG**.

### 4. Top Actors

The analysis identified actors with multiple appearances within the dataset.

Examples include:

- David Attenborough
- Vatsal Dubey and collaborators
- Samuel West
- Jeff Dunham
- Kevin Hart

### 5. Top Countries

The analysis examined the countries represented in the Netflix dataset.

The United States had the highest number of titles among the countries analyzed, followed by India and the United Kingdom.

### 6. Top Genres

The analysis identified frequently occurring genres and genre combinations.

Examples include:

- Dramas, International Movies
- Documentaries
- Stand-Up Comedy
- Comedies, Dramas, International Movies
- Children's & Family Movies

### 7. Top Directors

The analysis identified directors with multiple titles in the dataset.

The dashboard highlights directors including:

- Rajiv Chilaka
- Raúl Campos & Jan Suter
- Marcus Raboy
- Suhas Kadav
- Cathy Garcia-Molina

## 📊 Excel Dashboard

The project includes a visual Excel dashboard containing seven major visualizations:

- Percentage of Movies vs TV Shows
- Ratings distribution
- Content by release year
- Top 5 actors
- Top 10 titles
- Top 10 genres
- Top 10 directors

The dashboard combines summary information and visualizations to make the analysis easier to explore and interpret.

## 💡 Key Insights

The analysis shows that Movies make up a larger proportion of the dataset than TV Shows.

The dataset also contains a wide range of ratings, with TV-MA being the most frequently occurring rating.

Content production increased substantially in the years covered by the release-year analysis, with 2018 recording the highest number of titles.

The analysis also highlights the countries, genres, directors and actors that appear most frequently within the dataset.
