# Netflix Content Analysis

## 📌 Project Overview

This project analyzes Netflix content using Microsoft Excel to explore patterns and characteristics within the dataset.

An interactive Excel dashboard was developed to present the analysis through visualizations, filters and formatted summary information.

## 🎯 Objectives

- Explore the Netflix content dataset.
- Analyze the distribution of content.
- Identify patterns within the available content data.
- Create an interactive and visually engaging dashboard.
- Present findings in a clear and easy-to-understand format.

## 🛠️ Tools Used

- Microsoft Excel
- Data Cleaning
- Data Analysis
- PivotTables
- Data Visualization
- Excel Dashboard
- Filters

## 📊 Analysis & Dashboard

The project uses Excel to organize and analyze the Netflix dataset.

The dashboard incorporates:

- Interactive filters
- Charts and visualizations
- Formatted summary information
- Data analysis using Excel
- Dashboard layout and presentation

The filters allow users to interact with the dashboard and explore different sections of the dataset.

## 📈 Dashboard Design

The dashboard was designed to make the analysis easy to interpret by combining:

- Summary information
- Visual charts
- Interactive filtering
- Structured formatting

This demonstrates the use of Excel not only for calculations but also for creating an interactive reporting and visualization solution.

## 💡 Key Takeaways

The analysis provides a visual way to explore Netflix's content dataset and identify patterns within the available information.

The interactive dashboard makes it easier for users to filter the data and examine different aspects of the dataset.
