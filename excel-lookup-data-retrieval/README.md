# Excel Lookup & Data Retrieval Project

## 📌 Project Overview

This project demonstrates the use of Excel lookup and data retrieval functions to retrieve, match and organize information from structured datasets.

The project contains several practical Excel exercises involving employee information, student performance data, rating tables and commission data.

## 🛠️ Excel Skills Demonstrated

- VLOOKUP
- HLOOKUP
- INDEX
- Conditional Formatting
- Lookup Tables
- Data Retrieval
- Data Organization
- Basic Excel Calculations

## 🔎 Project Components

### 1. Rating Lookup

A rating table was used to convert performance ratings such as Excellent, Very Good, Good, Satisfactory, Fair, Poor and Fail into corresponding numerical scores using VLOOKUP.

### 2. Employee Information Lookup

An employee lookup section was created to retrieve employee information based on an employee ID.

The lookup retrieves:

- Last Name
- First Name
- Department
- Email
- Phone Extension
- Location
- Hire Date
- Pay Rate

VLOOKUP was used to retrieve the corresponding information from the employee master list.

### 3. Student Performance Lookup

The project also demonstrates HLOOKUP by retrieving student performance scores across:

- Mathematics
- Science
- English
- Music

The dataset was arranged horizontally to support the HLOOKUP exercise.

### 4. Conditional Formatting

Conditional formatting was used to highlight rows containing a particular performance rating.

### 5. Commission Data

The project includes a commission-related worksheet containing sales amounts and corresponding commission percentages for analysis and calculation.

## 🎯 Purpose

The project demonstrates practical Excel techniques for retrieving information from structured datasets and automating repetitive lookup tasks.

These skills are useful for tasks such as employee record management, reporting, data reconciliation and spreadsheet-based business analysis.
