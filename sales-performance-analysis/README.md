# Sales Performance Analysis

## 📌 Project Overview

This project analyzes sales data to understand revenue performance across products, regions and time periods.

The project demonstrates an end-to-end data analytics workflow using Microsoft Excel, SQL and Power BI to prepare, analyze and visualize sales information.

## 🎯 Objectives

- Analyze overall sales and revenue performance.
- Compare revenue across different products.
- Examine revenue performance by region.
- Analyze revenue trends over time.
- Create an interactive dashboard for business reporting.
- Use SQL to structure and manage sales data.

## 🛠️ Tools Used

- Microsoft Excel
- MySQL
- SQL
- Power BI

## 🗄️ SQL Database Work

The sales database was created using MySQL.

The database included:

- A `customers` table
- A `sales` table
- Primary key relationships
- Foreign key relationships
- Customer and sales records

SQL was used to create the database structure and insert the customer and sales data.

## 📊 Power BI Dashboard

An interactive Power BI dashboard was created to visualize sales performance.

### Key Dashboard Metrics

- Total Revenue: **₦3.27M**
- Total Quantity: **18**
- Total Sales: **11**

### Dashboard Visualizations

- Revenue by Product
- Revenue by Region
- Revenue by Month

### Interactive Filters

The dashboard includes filters for:

- Region
- Product

These filters allow users to explore the sales data from different perspectives.

## 🔍 Key Insights

The dashboard shows differences in revenue performance across products and regions.

The product analysis shows that phones and laptops generated higher revenue than tablets in the analyzed dataset.

The regional analysis shows Lagos as the highest-revenue region among the regions displayed on the dashboard.

The dashboard also provides a monthly view of revenue to support the identification of changes in sales performance over time.

## 💡 Business Value

The analysis provides a simple way for decision-makers to monitor sales performance, compare regions and products, and identify areas that may require further investigation.

## 📁 Project Components

## 📈 Conclusion

This project demonstrates the use of SQL, Excel and Power BI together to transform sales data into an interactive business reporting solution.
